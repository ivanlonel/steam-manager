# steam-manager

A command-line and local web application that gathers a Steam account's store and account data into a per-account SQLite database, and helps manage that account.

**Work in progress: nothing is usable yet.** The first milestone (catalog, wishlist and followed games from public data, HowLongToBeat times, exports) is being built.

## Documentation

https://ivanlonel.github.io/steam-manager/

## Development

See [CONTRIBUTING.md](CONTRIBUTING.md). In short: install [`uv`](https://docs.astral.sh/uv/), then `uv sync --locked` and `uv run pytest`.
